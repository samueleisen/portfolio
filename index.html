Architectural & FinOps Decisions

Engineering Philosophy

How I tend systems

Pillar 01 · Cloud & Cost Governance

FinOps by Architecture, Not Afterthought

Cloud infrastructure shouldn't leak money while idle. By pairing native Cloud Run ingress with scale-to-zero compute, right-sized Cloud SQL instances, and filtered log sinks, production stays responsive under load and costs ~$6/month at rest.

Pillar 02 · Closed-Loop Reliability

Alerts That Track & Resolve Themselves

Monitoring is only useful when it drives action without alert fatigue. Services bind to localhost behind Cloudflare Zero Trust tunnels while Gatus probes SLAs and automatically manages the full lifecycle of GitHub Incident issues.

Pillar 03 · Data Integrity First

Concurrency Enforced at the Storage Layer

Application-level checks fail when containers scale horizontally. Pushing invariants like reservation overlap prevention into PostgreSQL GiST exclusion constraints guarantees correctness regardless of how many API replicas are running.
